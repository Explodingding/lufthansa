# Recruiter Summary

## Project

**Airline Digital Experience Data Platform**

This is a portfolio data engineering project built around an airline digital product scenario. It demonstrates how I would deliver a data product from scratch for teams working between Middleware integration and Digital Hangar product analytics.

## What It Shows

- Python data engineering foundations.
- API-style extraction and synthetic fallback data.
- Data lake thinking with raw, bronze, silver, and gold layers.
- PySpark-oriented processing design.
- SQL-ready analytical outputs.
- Dataset exploration with Pandas and NumPy.
- Dashboarding with Streamlit.
- Testing with pytest.
- Code quality with Ruff.
- CI/CD and review-ready development workflow.
- Azure Data Factory and Databricks architecture awareness.

## Fast Review Path

For a quick review, start with `README.md`, then check the final demo flow, SQL examples under `sql/`, the Streamlit dashboard in `dashboard/app.py`, and the cloud blueprints under `cloud/`.

The role mentions high-quality data processing pipelines, dataset exploration, dashboards, API extraction, structured databases, modern data architecture, Azure Data Factory, Databricks, Git, pytest, Scrum, TDD, CI/CD, DevOps, clean code, and code review.

This project is intentionally structured to cover those responsibilities in a small but realistic scope. It is not a toy notebook; it is a compact data product with contracts, tests, architecture decisions, SQL insights, and a working dashboard.
